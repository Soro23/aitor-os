PROJECT

Proyecto

Trading Platform

En desarrollo

Plataforma para diseñar, probar y ejecutar estrategias de trading algorítmico sin depender de herramientas de terceros cerradas.

GitHubDemo

Problema

Necesitaba un lugar donde probar estrategias de trading algorítmico con datos en tiempo real, sin quedarme atado a plataformas cerradas de terceros ni a sus límites de personalización.

Solución

Backend en Node.js conectado a un exchange vía WebSocket, con un motor de reglas configurable y un dashboard en tiempo real para visualizar operaciones y resultados.

Arquitectura

Next.js (App Router) para el dashboard + un servidor WebSocket independiente para el stream de precios + PostgreSQL para histórico de operaciones + Redis como caché de precios en vivo.

Tecnologías

TypeScript · Next.js · PostgreSQL · Redis · WebSocket

Aprendizajes

Gestionar estado en tiempo real sin bloquear el hilo principal fue el mayor reto — terminé moviendo el procesamiento de datos a un worker independiente del servidor web.

Próximos pasos

Backtesting histórico, alertas por Telegram y soporte para múltiples exchanges en paralelo.
